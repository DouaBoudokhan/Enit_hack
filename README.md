# mycrew

CrewAI project scaffold aligned with the `crewai create` layout.

## Setup

1. Create a virtual environment and activate it.
2. Install dependencies:

```
pip install -r requirements.txt
```

3. Copy .env.example to .env and add your API key.

## Run

```
python -m mycrew.main
```

You can also run the root wrapper script:

```
python main.py
```
